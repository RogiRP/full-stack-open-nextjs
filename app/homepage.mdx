# Blog app

An application for sharing and reading interesting blogs, built during the
[Full Stack Open Next.js](https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs) course.

## Features

- Browse the list of blogs ordered by likes and search them by title
- Like the blogs you find useful
- Register and log in to add your own blogs
- Keep a personal reading list and mark blogs as read
- Generate a personal API token to access your information

## Technologies

The app is built with Next.js, React Server Components, Server Actions,
Drizzle ORM, PostgreSQL, NextAuth and Tailwind CSS.
